- Valuable user feedback

### Bug Prioritization

**P0 - Critical** (Fix within 24h):
- App crashes on launch
- Cannot create account
- Data loss
- Security issues

**P1 - High** (Fix within 3 days):
- Cannot create expense
- Cannot settle up
- Receipt scan fails every time
- Major UI breakage

**P2 - Medium** (Fix within 1 week):
- Minor UI issues
- Non-critical feature not working
- Inconsistent behavior

**P3 - Low** (Fix eventually):
- Cosmetic issues
- Nice-to-have features
- Edge cases
